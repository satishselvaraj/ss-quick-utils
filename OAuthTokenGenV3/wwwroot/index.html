🔒 Security Information

Where is my data stored?

  • All settings and tokens are stored in your browser's localStorage
  • Nothing is sent to any server other than your GitLab instance
  • The Application Secret is stored locally and used only for token exchange requests directly to your GitLab instance
  • This page can be hosted on GitLab Pages, a local web server, or opened as a local file

⚠️ Troubleshooting

"I don't have access to the file" error
  • Ensure files are committed and pushed to the remote repository
  • Verify the OAuth app has the api scope
  • Check the project is cloned from GitLab (not just a local folder)
  • Confirm the user has Reporter+ access to the project
"Unsupported language" in Code Suggestions
  • Go to Extensions > GitLab > Toggle Code Suggestions
  • Ensure the file has a recognized extension (e.g., .cs, .py, .js)
  • Update the GitLab extension to the latest version
  • Restart Visual Studio after updating
Token expires too quickly

Token expiration is controlled server-side by GitLab (default: 2 hours). Use the Refresh Token feature to renew without re-authorizing. Admins can increase the duration in gitlab.rb:

gitlab_rails['doorkeeper_access_token_expires_in'] = 86400
